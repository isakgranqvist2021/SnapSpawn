
# SnapSpawn

An app where you can generate images with openai, buy credits to generate images.

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file. 

Create a .env file in the app directory and add these variables.


`MONGO_DB_DATABASE_URL`

`AUTH0_BASE_URL`

`AUTH0_CLIENT_SECRET`

`AUTH0_CLIENT_ID`

`AUTH0_ISSUER_BASE_URL`

`AUTH0_SECRET`

`GCP_BUCKET_NAME`

`GCP_CLIENT_EMAIL`

`GCP_CLIENT_ID`

`GCP_PRIVATE_KEY`

`GCP_PROJECT_ID`

`OPEN_AI_API_KEY`

`STRIPE_SECRET_KEY`

`GMAIL_EMAIL`

`GMAIL_PASSWORD`


## Installation

Install SnapSpawn with npm

```bash
  cd app
  npm install
```
    
## Running Tests

To run tests, run the following command

```bash
  cd app
  npm run test
```


## Tech Stack

**Tech:** React (Next.js), Vercel, Auth0, Stripe, MongoDB (Atlas), Google Cloud (Bucket)

**Styling:** TailwindCSS (DaisyUI)
